# Polare koordinater – miniapp

Denne miniappen lar deg:

- Visualisere opptil tre polare funksjoner `r(θ)` og slå dem av/på individuelt.
- Konvertere mellom kartesiske og polare koordinater.

## Kom i gang

1. Installer avhengigheter:
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Start appen:
   ```bash
   streamlit run app.py
   ```

Appen er laget for å passe i et normalt skjermoppsett med et kompakt og oversiktlig layout.
